# Скомпилировать скрипт встречи с позициями в YAML

Выделить движок языка в отдельный SPM-пакет. Лексер читает базовый синтаксис и сохраняет позиции. Реестр находит по имени тип выражения, которое разбирает свои аргументы через общий интерфейс и строит типизированную модель. Скомпилированный скрипт имеет тип результата и контекста исполнения.

Для встречи с курьером нужны `chooseOne`, `case`, `caseIf`, `do`, `hasItem`, `removeItem`, `addItem` и `say`. При сборке встречи `GameEngine` предоставляет набор игровых команд и каталог известных предметов для проверки ID. [Грамматика и типы](../../ScriptLanguage.md) · [Исходник события](../../../Fixtures/Campaigns/LastTrain/events/collect-parcel/courier.yaml)

## Что проверить на ревью

Тест берёт поле `script` из настоящего YAML и компилирует обе ветки. В тестовой копии неизвестный ID предмета или значение неподходящего типа дают ошибку до исполнения. Диагностика указывает путь от корня кампании, строку и столбец в исходном файле с отсчётом от единицы.
