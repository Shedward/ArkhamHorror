# PR 8. Установить и обновить кампанию из файла

Подключить открытие `.districtdeck` из Finder и «Файлов» к локальной библиотеке кампаний и валидатору `CampaignArchive`. Внешнюю кампанию распознавать по `id`, при изменении предложить замену для новых партий. Изменившуюся встроенную кампанию обновлять автоматически. [Установка и обновление](../../Architecture.md)

## Что проверить на ревью

Установить архив на Mac и iPad. Начать партию, затем установить исправленный архив с прежними `id` и версией, но другой репликой курьера. После замены старая партия показывает исходный текст, новая — обновлённый. Обе открываются офлайн.
