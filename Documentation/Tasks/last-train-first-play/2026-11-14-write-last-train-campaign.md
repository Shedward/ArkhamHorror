# PR 1. Подготовить исходники «Последнего поезда»

Добавить в `Fixtures/Campaigns/LastTrain/` файл `campaign.yaml` с постоянным `id`, названием и версией, граф карты с территориями, персонажа со стартовой раскладкой, квест, три встречи, сюжетные точки и ресурсы, на которые они ссылаются. Это пример формата для обсуждения с автором. [Сценарий и раскладка](../../Campaigns/LastTrain.md)

## Что проверить на ревью

По YAML проследить путь посылки через курьера и через почту до проводника. Найти связь двух входов с одной территорией вокзала. Сверить очерёдность двух условий в пятом раунде и тексты обеих развязок.

Исходники начинаются с [campaign.yaml](../../../Fixtures/Campaigns/LastTrain/campaign.yaml). При сверке по YAML поезд появился на отметке 2 на всех маршрутах. Через курьера посылка отправлена в третьем раунде, через почту — в пятом. При задержке в пятом раунде поезд ушёл, пять монет и посылка остались у Ивана. На почтовом маршруте в срок одновременно подошли оба перехода, сработал первый.

## Решения

- В `board/map.yaml` перечисляем территории в `territories`, а клетки — в `cells`. Записи в обоих разделах имеют свой ID и видимое игроку `name`. У клетки можно указать ID её территории в `territory`. Каждую двустороннюю дорогу записываем один раз в `edges` парой ID клеток. [Граф «Последнего поезда»](../../Campaigns/LastTrain.md#поле)
- Файл `characters/ivan.yaml` содержит `id` и имя Ивана. Основной YAML задаёт состав через `characters: { required: ivan, maxCount: 1 }`. Общая стартовая клетка — `initialPoint: station-start`. Скрипт кампании `onStart` выдаёт Ивану пять монет перед открытием первой сюжетной точки.
- Основной YAML кампании задаёт стартовую точку сюжета по её `id`: `initialStoryPoint: send-parcel`. В начале новой партии движок открывает точку «Отправить посылку» (`send-parcel`). Действие этой точки при открытии выдаёт квест «Забрать посылку» (`collect-parcel`).
- В `track` лежат размеры шкалы `maxHope`, `maxDespair` и список `transitions` в порядке проверки. В `at` автор указывает конкретный числовой порог для надежды или отчаяния. На этом делении игрок видит значок с описанием `description`. Поле `when` задаёт дополнительное условие, `to` указывает следующую точку. У развязки опускаем `track`. [Оба перехода «Последнего поезда»](../../Campaigns/LastTrain.md#сюжетная-карта-отправить-посылку)
- Каждому событию соответствует отдельный YAML с текстом встречи, вариантами ответа и эффектами каждого ответа. Например, в файле курьера можно прочитать оба ответа и увидеть, что произойдёт при обмене и при отказе.
- Встречи ссылаются на предметы и события по явным `id`. Синтаксис, проверка ссылок и повторный запуск прерванной встречи описаны в [правилах языка](../../ScriptLanguage.md).
- У квеста `onStart`, `completeWhen` и `onComplete` лежат прямо в корне YAML. При выдаче «Забрать посылку» скрипт `onStart` кладёт курьера на площадь и выдачу посылки на почту, обе карты наверх с `forQuest: (currentQuest)`. Условие `completeWhen` только читает состояние партии и возвращает `Bool`. Здесь это `(hasItem .parcel in: all)`. При выполнении квеста `onComplete` кладёт проводника на вокзал вызовом `(placeEvent .conductor .station position: top)`.
- Для событий, квестов, точек сюжета и предметов действуют общие правила. На каждую сущность приходится один YAML. Сборщик обходит `events/`, `quests/`, `story/` и `items/` соответственно, включая подпапки. Перечислять файлы в манифесте не требуется.
- У монеты, посылки и записки проводника свои файлы в `items/`. Встречи и стартовый инвентарь ссылаются на предметы по `id`. По мере развития модели автор сможет дополнить описание отдельного предмета в его файле.
- Имя файла без расширения совпадает с коротким `id` внутри YAML. Идентификатор уникален среди сущностей того же типа в кампании. Квест ссылается на событие `courier` по его `id`, поэтому файл `courier.yaml` можно перемещать внутри `events/`. При сборке валидатор проверяет имена файлов, уникальность идентификаторов и ссылки.
- Внутри `events/` автор группирует квестовые события по квесту, а обычные — по территории. Обе встречи квеста «Забрать посылку» лежат рядом в `events/collect-parcel/`: `courier.yaml` и `post-office.yaml`. Подпапки служат только для поиска. Момент добавления события и его колоду задают правила кампании.
