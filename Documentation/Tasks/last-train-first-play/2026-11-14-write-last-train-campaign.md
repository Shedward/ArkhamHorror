# PR 1. Подготовить исходники «Последнего поезда»

Добавить в `Fixtures/Campaigns/LastTrain/` основной YAML с постоянным `id`, названием и версией, граф карты с территориями, персонажа со стартовой раскладкой, квест, три встречи, сюжетные точки и ресурсы, на которые они ссылаются. Это пример формата для обсуждения с автором. [Сценарий и раскладка](../../Campaigns/LastTrain.md)

## Что проверить на ревью

По YAML проследить путь посылки через курьера и через почту до проводника. Найти связь двух входов с одной территорией вокзала. Сверить очерёдность двух условий в пятом раунде и тексты обеих развязок.

## Решения

- Файл `characters/<id>.yaml` содержит `id` персонажа и имя, которое видит игрок. В разделе `setup` основного YAML автор ссылается на персонажа по `id` и задаёт его стартовую клетку и начальный инвентарь. В «Последнем поезде» один персонаж начинает на клетке «Вокзал · старт» с одним жетоном.
- Основной YAML кампании задаёт стартовую точку сюжета по её `id`: `initialStoryPoint: send-parcel`. В начале новой партии движок открывает точку «Отправить посылку» (`send-parcel`). Действие этой точки при открытии выдаёт квест «Забрать посылку» (`collect-parcel`).
- Каждому событию соответствует отдельный YAML с текстом встречи, вариантами ответа и эффектами каждого ответа. Например, в файле курьера можно прочитать оба ответа и увидеть, что произойдёт при обмене и при отказе.
- Встречи ссылаются на предметы и события по явным `id`. Синтаксис, проверка ссылок и повторный запуск прерванной встречи описаны в [правилах языка](../../ScriptLanguage.md).
- Квест «Забрать посылку» при выдаче кладёт событие «Курьер» наверх колоды площади. Так по квесту видно, когда и где игрок сможет встретить курьера.
- Для событий, квестов, точек сюжета и предметов действуют общие правила. На каждую сущность приходится один YAML. Сборщик обходит `events/`, `quests/`, `story/` и `items/` соответственно, включая подпапки. Перечислять файлы в манифесте не требуется.
- У жетона, посылки и записки проводника свои файлы в `items/`. Встречи и стартовый инвентарь ссылаются на предметы по `id`. По мере развития модели автор сможет дополнить описание отдельного предмета в его файле.
- Имя файла без расширения совпадает с коротким `id` внутри YAML. Идентификатор уникален среди сущностей того же типа в кампании. Квест ссылается на событие `courier` по его `id`, поэтому файл `courier.yaml` можно перемещать внутри `events/`. При сборке валидатор проверяет имена файлов, уникальность идентификаторов и ссылки.
- Внутри `events/` автор группирует квестовые события по квесту, а обычные — по территории. Обе встречи квеста «Забрать посылку» лежат рядом в `events/collect-parcel/`: `courier.yaml` и `post-office.yaml`. Подпапки служат только для поиска. Момент добавления события и его колоду задают правила кампании.
