# PR 4. Собрать и загрузить архив кампании

Добавить `CampaignArchive` и CLI `CampaignTool`. Утилита проверяет папку с YAML и ресурсами и упаковывает её в `.districtdeck`. Загрузчик читает ZIP, проверяет его теми же правилами и строит модель для `GameEngine`. Добавить пример команды сборки и тесты трёх маршрутов из собранного архива. [Формат и валидация](../../Architecture.md)

## Что проверить на ревью

Собрать «Последний поезд» из исходников одной командой. Тесты из одного архива дают «Посылка отправлена» в раундах 3 и 5, «Поезд ушёл» в раунде 5. В копии с неизвестной территорией сборка и загрузка указывают файл и ошибочную ссылку.

В маршруте через площадь довести партию от начальной раскладки до курьера обычными действиями. Проверить результат обмена и его последствия для квеста. Монеты списаны, посылка у Ивана, квест закрыт, на почте больше нет выдачи, на вокзале один проводник. [Тест скрипта встречи](2026-11-14-resolve-courier-encounter.md) · [Интеграционный тест квеста](2026-11-14-play-game-engine-rounds.md#связь-встречи-с-квестом)

В тестовой копии `story/send-parcel.yaml` заменить `onRoundEnd` на `onRoundEn`. Сборка папки и открытие архива с той же опечаткой должны завершиться ошибкой. В обоих сообщениях проверить имя `onRoundEn`, путь `story/send-parcel.yaml`, строку и столбец первой буквы поля.

Проверить ссылку на встроенную `.hope` и ссылку на авторскую `.parcel`. Обе разрешаются при сборке и при загрузке. Если в тестовой копии добавить `items/hope.yaml` с ID `hope`, обе проверки указывают на этот файл и сообщают, что ID занят системным ресурсом. [Доменная модель](../../DomainModel.md)

В копии архива убрать `resources/board/train.png`. Сборка папки и открытие архива указывают на ссылку `"@board/train.png"` в `board/scene.yaml`. Теми же проверками отклоняется путь за пределами `resources/`. Для каждой записи `edgePaths` проверить, что пара клеток задаёт существующее ребро карты.
