# Рассмотреть явную проверку условия квеста из скрипта

Когда появится сценарий, которому важно проверить квест в определённом месте скрипта, обсудить с автором команду вида `(checkQuest .some-id)`. Идея — попросить движок проверить текущее условие активного квеста. При выполненном условии квест завершается по обычным правилам, при невыполненном остаётся активным.

Сверить пример с автоматической проверкой сразу после эффектов выдачи и с выбранным моментом проверки в раунде. Обсудить команду, если сценарию потребуется проверить квест между этими моментами. [Доменная модель](../../DomainModel.md)
