# Последний поезд

В «Последнем поезде» игрок ведёт Ивана, который приходит на вокзал с пятью монетами. До отправления поезда он должен получить посылку и передать её проводнику. У курьера это можно сделать быстрее, на почте — сохранить деньги. Архив один и тот же для игры на Mac или iPad и для прогона без экрана. Ниже приведены раскладка и ожидаемые результаты по [базовым правилам](../GameRules.md).

[Исходники кампании](../../Fixtures/Campaigns/LastTrain/campaign.yaml) · [Руководство по формату](../CampaignFormat.md)

## Начальная раскладка

В архиве один файл персонажа — `characters/ivan.yaml`, поэтому список `allowed` можно опустить. В корневом `campaign.yaml` раскладка отводит Ивану единственное место в партии.

```yaml
id: last-train
name: Последний поезд
version: "1.0"

characters:
  required: ivan
  maxCount: 1

rules:
  actionPoints:
    - count: 1
      actions: [move]
  actionLimits: { move: 1 }
  movementRange: 2

initialPoint: station-start
onStart: |
  (addItem .coin in: .ivan count: 5)
initialStoryPoint: send-parcel
```

Перед первым ходом поверх карты открывается точка сюжета «Отправить посылку». После нажатия «К карте» игрок видит цель «Отправить посылку» рядом со шкалой надежды и отчаяния, а задание «Забрать посылку» — в списке квестов.

| Механика | Значение в кампании |
| --- | --- |
| Персонаж | Один, на клетке «Вокзал · старт». В личном инвентаре пять монет. Посылки и записки нет. |
| Ход | Одно очко только на перемещение. За него можно пройти один или два шага. Можно сразу завершить ход и остаться. В обоих случаях после хода движок проверяет активные квесты, затем разыгрывает встречу. |
| Сюжет | Открыть «Отправить посылку». Надежда 0, отчаяние 0. Квест «Забрать посылку» выдан при открытии точки. |
| Колоды территорий | Все стартовые колоды пусты и опущены в YAML. При выдаче квеста «Забрать посылку» его скрипт `onStart` кладёт «Курьера» на площадь и «Выдачу посылки» на почту. Обе территории подсвечены. Вокзал остаётся пустым до появления проводника. |
| Расписание поезда | В начале партии платформа пуста. В конце каждого раунда после встреч прибавляется 1 отчаяние. На отметке 2 поезд прибывает и к первому действию третьего раунда уже стоит у платформы. Отметка 5 — крайний срок передачи посылки. |
| Порядок событий | Курьера, выдачу посылки на почте и встречу с проводником кладём наверх соответствующих колод (`position: top`). Все три маршрута обходятся без случайности. |

### Предметы и ресурсы

Монета (`coin`), посылка (`parcel`) и записка проводника (`conductor-note`) принадлежат персонажу. Например, `items/parcel.yaml` содержит такое описание.

```yaml
id: parcel
name: Посылка
owner: character
```

У монеты игрок видит название «Монета» и количество. У записки в `items/conductor-note.yaml` есть ещё и текст, который можно открыть и перечитать в инвентаре. Например:

```yaml
id: conductor-note
name: Записка проводника
owner: character
text: Посылку принял. Доставлю лично. Поезд № 17, вагон 3.
```

Монеты, посылка и записка видны в личном инвентаре Ивана, пока они у него есть. В их YAML поле `showInInventory` можно опустить. Для надежды (`hope`) и отчаяния (`despair`) движок задаёт `owner: party` и `showInInventory: false` во встроенных описаниях. Игрок видит оба значения на сюжетной шкале уже в первом раунде, когда они равны нулю.

### Поле

Каждая линия на схеме — один шаг в любую сторону. «Улица», «Перекрёсток» и «Переулок» находятся вне территорий. Две клетки вокзала относятся к одной территории и используют одну колоду. У площади и почты по одной клетке и своей колоде.

```text
Вокзал · старт — Улица — Перекрёсток — Площадь — Переулок — Почта
                             \          /
                             Вокзал · вход
```

Короче всего от старта до почты идти пять шагов по верхней линии. От почты обратно до второго входа три шага. Встреча разыгрывается там, где персонаж остановился. Через площадь можно пройти за одно перемещение, оставив курьера в колоде. Для маршрутов ниже существен именно выбор клетки остановки.

В `board/map.yaml` у территорий и клеток свои списки. Ключ записи — её ID, `name` — название для игрока. Клетка может ссылаться на одну территорию через `territory`. В `edges` каждая пара ID клеток задаёт дорогу в обе стороны.

```yaml
territories:
  station: { name: Вокзал }
  square: { name: Площадь }
  post-office: { name: Почта }

cells:
  station-start: { name: Вокзал · старт, territory: station }
  street: { name: Улица }
  crossroads: { name: Перекрёсток }
  square: { name: Площадь, territory: square }
  alley: { name: Переулок }
  post-office: { name: Почта, territory: post-office }
  station-entrance: { name: Вокзал · вход, territory: station }

edges:
  - [station-start, street]
  - [street, crossroads]
  - [crossroads, square]
  - [square, alley]
  - [alley, post-office]
  - [crossroads, station-entrance]
  - [square, station-entrance]
```

### Оформление поля

Для первой пробы берём готовую иллюстрацию города. В `board/scene.yaml` автор указывает фон и размечает клетки по ID из `board/map.yaml`. Контур `polygon` задаёт область выбора и подсветки, а `pawn` — точку остановки фишки. В `objects` автор описывает объекты карты по ID. Контуры, места для фишек и позиции объектов используют координаты одного холста с началом в левом верхнем углу. Ссылка `"@board/city.png"` указывает на `resources/board/city.png` в корне кампании. Ссылки с начальным `@` в YAML заключают в кавычки.

В необязательном списке `edgePaths` автор задаёт повороты для дороги из графа. От `pawn` первой клетки фишка проходит через точки `via` по порядку до `pawn` второй. На обратном пути точки читаются в обратном порядке. Без записи фишка идёт по прямой. В обоих случаях дорога стоит один шаг.

Фрагмент [сцены кампании](../../Fixtures/Campaigns/LastTrain/board/scene.yaml):

```yaml
edgePaths:
  - edge: [crossroads, station-entrance]
    via: [[453, 553], [453, 687], [640, 687]]
objects:
  train:
    image: "@board/train.png"
    position: [763, 583]
```

Рельсы нарисованы на фоне, поезд хранится отдельной картинкой. При достижении отметки отчаяния скрипт сюжетной точки ставит поезд у платформы. При входе в любую из двух развязок `(removeObject .train)` показывает его отправление.

Оба входа имеют собственные контуры и места для фишек. Когда в колоде территории `station` появляется проводник, подсвечиваются оба входа. Игрок выбирает конкретный вход, а движок считает путь по графу в `board/map.yaml`.

## Квест и карты встреч

В `quests/collect-parcel.yaml` задание и подсказка лежат рядом с условием выполнения и скриптами квеста.

```yaml
id: collect-parcel
goal: Забрать посылку
text: Курьер на площади возьмёт пять монет за доставку. На почте посылку выдадут бесплатно.
onStart: |
  (do
    (placeEvent .courier .square position: top forQuest: (currentQuest))
    (placeEvent .post-office .post-office position: top forQuest: (currentQuest)))
completeWhen: "(hasItem .parcel in: all)"
onComplete: |
  (placeEvent .conductor .station position: top)
```

При открытии точки «Отправить посылку» игрок получает квест с постоянной целью «Забрать посылку». При выдаче задания он узнаёт о двух путях — через курьера на площади или через почту. Условие квеста — у персонажа есть посылка. Обе карты добавлены с `forQuest:`, поэтому движок проверяет условие после розыгрыша любой из них. При отказе у курьера квест остаётся активным. При получении посылки квест завершается, его оставшиеся карты выбывают из колод, а скрипт выполнения кладёт на вокзал одну карту «Проводник». Все эти последствия входят в сохранение встречи. Передать ему посылку — основная цель точки «Отправить посылку». В описаниях курьера, выдачи на почте и проводника указано `hint.highlight: mainQuest`. После получения посылки из этих карт в стопках остаётся только проводник, поэтому теперь подсвечен вокзал.

| Встреча | Что видит и делает игрок | Что меняется |
| --- | --- | --- |
| Курьер · площадь | Курьер просит пять монет за доставку. Если денег меньше, «Заплатить 5 монет» недоступно с подсказкой «Нужно 5 монет». «Отказаться» доступно всегда и требует нажатия даже при включённом автоподтверждении. | При оплате Иван отдаёт ровно пять монет и получает посылку. При отказе деньги остаются у него, квест остаётся активным, а в журнале сохраняется реплика «Тогда заберёте посылку на почте». При любом ответе курьер уходит в сброс. |
| Выдача посылки · почта | Служащий находит отправление. Игрок читает текст и нажимает «Забрать посылку». | До подтверждения посылка у служащего, квест активен. При подтверждении выдать персонажу одну посылку. Деньги остаются у Ивана. Если курьер ещё в колоде площади, выполнение квеста убирает его. |
| Проводник · вокзал | Проводник обещает доставить отправление. Игрок нажимает «Передать посылку». | При подтверждении списать посылку, выдать записку с обещанием проводника, номером поезда и вагона, добавить 1 надежду текущей цели. Передача доступна у любого входа по общей колоде. |

Каждая разыгранная карта уходит в сброс. Если колода опустела или ход закончился на улице вне территории, встреча пропускается. Отчаяние в конце такого раунда начисляется как обычно.

## Сюжетная карта «Отправить посылку»

При каждом входе в «Отправить посылку» движок выполняет `onEnter`. Скрипт выдаёт квест «Забрать посылку». Пока точка активна, после всех встреч раунда `onRoundEnd` добавляет одно очко отчаяния. Затем движок разыгрывает достигнутые отметки и проверяет переходы в **порядке строк**. Открывается первая подходящая точка. Если обе проверки не дали перехода, начинается следующий раунд.

В `track` автор задаёт размеры шкалы и переходы. Шкала показывает текущие количества из общего инвентаря. Число в `at` задаёт деление для значка перехода и минимальное количество соответствующего ресурса. Дополнительное условие можно указать в `when`. Пока точка активна, игрок видит короткое `description` перехода. Текст следующей точки открывается при переходе.

```yaml
id: send-parcel
text: >-
  Поезд прибудет к началу третьего раунда. Передайте посылку проводнику на вокзале до конца пятого раунда.
  Курьер на площади отдаст её за пять монет, а на почте её можно забрать бесплатно.
goal: Отправить посылку
onEnter: |
  (startQuest .collect-parcel)
onRoundEnd: |
  (addItem .despair)
track:
  maxHope: 1
  maxDespair: 5
  milestones:
    - at: { despair: 2 }
      description: Прибытие поезда
      script: |
        (do
          (addObject .train)
          (say "Последний поезд прибывает на вокзал."))
  transitions:
    - at: { hope: 1 }
      when: "(hasItem .conductor-note in: all)"
      description: Передайте посылку проводнику.
      to: parcel-sent
    - at: { despair: 5 }
      description: Опоздание — конец партии.
      to: train-left
```

«Посылка отправлена» и «Поезд ушёл» — две конечные точки. Игрок читает текст достигнутой развязки, а движок сохраняет эту точку как результат завершённой партии. Если записку получили в пятом раунде, подходят обе строки. По их порядку открывается «Посылка отправлена». Приоритет можно проверить, переставив строки в тестовой копии кампании.

У обеих развязок `onEnter` убирает поезд с карты, а поле `track` опущено. Например, в `story/parcel-sent.yaml` автор пишет:

```yaml
id: parcel-sent
text: Проводник принимает посылку. Поезд трогается.
onEnter: |
  (removeObject .train)
```

## Три прохождения из одной раскладки

Эти три маршрута служат эталоном для проверки проходимости кампании. Каждый начинаем из одной и той же раскладки и сверяем развязку и номер раунда с таблицей. В таблице указана **конечная клетка** каждого перемещения. В первом раунде путь до перекрёстка проходит через улицу. Отчаяние указано на момент проверки сюжета.

| Раунд | Через курьера | Через почту | Через почту с задержкой | Отчаяние |
| --- | --- | --- | --- | --- |
| 1 | Перекрёсток, встречи нет | Перекрёсток, встречи нет | Перекрёсток, встречи нет | 1 |
| 2 | Площадь. Заплатить 5 монет | Площадь. Отказаться от обмена | Площадь. Отказаться от обмена | 2 — после встречи прибывает поезд на всех маршрутах |
| 3 | Вокзал · вход. Передать посылку. **Посылка отправлена** | Почта. Получить посылку | Переулок. Остановиться после одного шага, встречи нет | 3 |
| 4 | Партия окончена | Площадь. Колода пуста | Почта. Получить посылку | 4 |
| 5 | Партия окончена | Вокзал · вход. Передать посылку. **Посылка отправлена** | Площадь. Колода пуста. **Поезд ушёл** | 5 |

У курьера Иван потратил пять монет и успел с запасом. Через почту он сохранил все пять монет и успел в последний раунд. С задержкой он остался на площади с пятью монетами и посылкой, без записки. Игрок также может с первого хода направиться прямо на почту. Например, остановиться по очереди на перекрёстке, в переулке, на почте, на площади и у второго входа вокзала. Тогда квест уберёт невытянутого курьера с площади в третьем раунде.

## Что проверить на партии

- **Посылка уже у персонажа.** В отдельной стартовой позиции положить посылку в личный инвентарь до выдачи квеста. При выдаче курьер попадает на площадь, а выдача посылки — на почту. Сразу после этого условие выполняется. Обе невытянутые карты уходят из партии, оба сброса пусты, а в колоде вокзала до первого хода лежит один проводник. Посылка у персонажа, передать её ещё предстоит.
- **Посылка получена без проверки.** Фиксированная позиция после ходов персонажей: персонаж с посылкой стоит на вокзале, квест активен, курьер и почтовая выдача ещё в колодах, колода вокзала пуста. Общая проверка завершает квест: обе невытянутые карты выбывают, сбросы остаются пустыми. На вокзале появляется ровно один проводник, и персонаж встречает его в этом же раунде.
- **Первый ход.** Прочитать вступление и нажать «К карте». На поле видны цель и квест. Персонаж на вокзале, у него доступно одно очко перемещения первого раунда, отчаяние равно нулю.
- **Прибытие.** Во время встречи с курьером во втором раунде платформа ещё пуста. После обмена или отказа отчаяние достигает двух, поезд появляется на карте, а в журнале — одна запись о прибытии. При загрузке в начале третьего раунда поезд уже виден, сообщение о прибытии повторно не разыгрывается. На быстром маршруте в этом же раунде можно передать посылку проводнику.
- **Карта и фишка на Mac и iPad.** В первом раунде сдвинуть и приблизить карту, пока фишка стоит на вокзале. Очко перемещения должно остаться доступным. Выбрать перекрёсток и нажать «Переместиться». Проверить, удобно ли после приближения выбрать нужную клетку и видно ли, как фишка проходит через улицу и останавливается на перекрёстке.
- **Две развязки.** Пройти каждый столбец таблицы через интерфейс и без экрана. На тех же ходах должны совпасть инвентарь, изменения колод, счётчики перед проверкой и конечная точка. В журнале видна причина каждого изменения.
- **Повторное прохождение.** Закончить маршрут через почту с задержкой и начать отдельную партию той же кампании. Из списка снова открыть завершённую партию, перечитать развязку «Поезд ушёл» и найти в её журнале остановку в переулке в третьем раунде. Вернуться к новой партии и проверить, что персонаж начинает на вокзале с пятью монетами, а журнал отражает только новое прохождение.
- **Подсказка после отказа.** На маршруте через почту во втором раунде осмотреть с перекрёстка сначала переулок, затем площадь. Очко перемещения тратится при нажатии «Переместиться» на площадь. Переиграть этот переход нельзя. На встрече нажать «Отказаться». Отказ окончателен, курьер уходит в сброс. В начале третьего раунда открыть журнал и перечитать реплику курьера о почте. В списке заданий по-прежнему активен квест «Забрать посылку».
- **Граница пятого раунда.** При передаче посылки в последний момент одновременно есть записка, 1 надежда и 5 отчаяния. В основной кампании открывается только «Посылка отправлена». В копии с обратным порядком условий из той же позиции открывается только «Поезд ушёл».
- **Сохранение.** Во втором раунде закрыть игру на предложении курьера до ответа. После запуска офлайн тот же курьер заново предлагает обмен на площади, все пять монет на руках, отчаяние равно 1. Принять обмен и снова открыть игру после завершения встречи. В начале третьего раунда, до первого действия, сравнить партию с непрерывным прохождением через курьера. Персонаж на площади с одним очком перемещения и одной посылкой, все пять монет потрачены. «Курьер» в сбросе площади, в колоде вокзала один «Проводник». Отчаяние равно 2.
- **Ожидание встречи.** В отдельной раскладке положить обычное событие перед курьером. Оно разыгрывается первым и уходит в сброс, площадь продолжает подсвечиваться. Завершить следующий ход на месте. Теперь персонаж встречает курьера.
- **Осмотр и общая колода.** С улицы площадь достижима за два шага, почта находится дальше. Осмотреть обе без траты очка. Из отдельной позиции на перекрёстке с посылкой и картой проводника в колоде вокзала проверить оба назначения: до второго входа один шаг, до стартового два. С каждого входа тянется та же карта.
- **Очистка колод.** После обмена на площади «Курьер» лежит в сбросе площади, а «Выдача посылки» убрана из партии и сброс почты пуст. Если сразу забрать посылку на почте, «Выдача посылки» лежит в сбросе почты, а «Курьер» убран из партии и сброс площади пуст. В отдельной позиции отменить квест до розыгрыша любой из двух встреч. Обе карты выбывают из партии, сбросы остаются пустыми. Остальные карты сохраняют свои места в колодах. Территория подсвечена, пока хотя бы у одной оставшейся в стопке карты указан `mainQuest`.
